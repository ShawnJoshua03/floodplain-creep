## Tooling
- `python3` is a Microsoft Store stub on the dev machine, so the Makefile runs Python through
  `uv run` and calls `python`.
- GNU make installed with winget package `ezwinports.make` (user scope), since Windows has none.
- `scripts/dump_openapi.py` imports `api.main` inside `main()` after the path is set. This avoids
  an `# noqa: E402` suppression.

## Frontend tooling
- `typescript` is pinned to 5.9.x. Root cause: typescript-eslint accepts `<6.1` and openapi-typescript accepts `^5`, so the latest 7.x fails to install. Revisit when both widen their range.
- `web/src/main.tsx` creates its mount node with `document.createElement`. This keeps the no-DOM-lookup rule intact outside MapView.tsx.
- `web/openapi.json` is generated by `make types` from `scripts/dump_openapi.py`. Do not hand-edit it or `web/src/api/generated/`.
