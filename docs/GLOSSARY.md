# Glossary

- **cell**: one square of the 100 m analysis grid. Cell data stays in local pipeline files.
- **neighborhood**: an admin boundary polygon. The smallest unit shown anywhere.
- **exposure**: buildings on ground the modeled flood layer marks as flooded for a return period.
- **return period**: average years between floods of a given size (10, 50, 100, 500). A model scenario, not a forecast.
- **suppressed**: a neighborhood-year with fewer than K buildings in the zone. Counts are null and the UI says "not enough data".
- **buildings in zone**: summed fractional building count in flood-zone cells of a neighborhood, for one year and return period.
- **new buildings in zone**: buildings in zone for a year minus the 2018 value. Shown only when both years reach K.
- **growth**: new buildings in zone as a percent of the 2018 value.
- **growth type**: a pattern label for how buildings were added. Not a wealth label.
